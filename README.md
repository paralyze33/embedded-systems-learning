# 嵌入式系统学习仓库

这是一个用于系统学习嵌入式开发、记录实践过程并沉淀独立项目的长期仓库。

## 学习目标

- 掌握 C 语言核心语法、指针、内存管理与模块化编程。
- 熟悉 STM32 的 GPIO、定时器、中断、ADC、DMA 及常用通信接口。
- 理解 FreeRTOS 的任务调度、队列、信号量、互斥锁与软件定时器。
- 能够独立完成嵌入式项目的需求分析、驱动开发、调试和文档整理。
- 形成可复用的代码、笔记与工程模板，为求职和后续项目积累作品。

## 技术路线

1. **C 语言基础**：语法、指针、结构体、位运算、数据结构与工程化。
2. **STM32 裸机开发**：开发环境、外设驱动、中断、通信协议与调试方法。
3. **FreeRTOS**：任务管理、同步与通信、内存管理和实时系统设计。
4. **综合项目**：把所学内容应用到完整、可演示、可复现的项目中。
5. **复盘沉淀**：持续整理学习笔记、问题记录和项目文档。
